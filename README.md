# Python and Database Assignment

## Task 1: API Data Retrieval and Storage
This task fetches book information from the Open Library REST API using Python. The retrieved data, including book title, author, and publication year, is stored in a local SQLite database called `books.db`. The saved records can be viewed using the SQLite Explorer extension in VS Code.

**File:** `collect_books.py`  
**Database:** `books.db`

## Task 2: Data Processing and Visualization
This task retrieves student test scores from an API, calculates the average scores, and displays the results using Python. Matplotlib is used to create a bar chart for visualizing the average scores.

**File:** `student_scores.py`  
**Output:** `student_average_scores.png`

## Task 3: CSV Data Import to Database
This task reads user information, including names and email addresses, from a CSV file and inserts the data into a local SQLite database. SQL queries are used to retrieve and display the stored records.

**File:** `csv_to_sqlite.py`  
**Input:** `user.csv`  
**Database:** `users.db`
